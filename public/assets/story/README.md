# Story artwork

`cream-roses.webp` is an optimized copy of the project's existing cream-rose artwork. It decorates the story section until the couple supplies their own photographs.

The attached mobile screenshot is an RSVP layout reference, not a couple portrait, so it is not published as a story photo.

Approved couple photos are uploaded from `/admin` to the private `wedding-assets/story/` storage folder. They do not enter Git or this public directory. Captions, order and story text are saved in `wedding_story`; only a published selection is returned to guests with temporary signed image URLs.
