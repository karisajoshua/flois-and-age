# Roadmap

1. Documentation — establish scope and repository conventions.
2. Foundation — scaffold React/TypeScript/Vite, Tailwind, routing, design tokens, lint and build checks.
3. Creative assets — generate independent layers, obtain approved media and optimize assets.
4. Guest experience — implement envelope, chapters, storybook, venue and accessible controls.
5. Backend — review schema and security, configure Supabase, implement direct RSVP for one guest or a couple and persistence tests.
6. Dashboard — authenticated guest management, live counts, exports and content editing.
7. QA — verify allocations, duplicate handling, permissions, mobile browsers, reduced motion, map links and performance.
8. Deployment — configure Vercel, environment variables, approved content and handover.

Acceptance: guest can open invitation, navigate directly to RSVP, submit one or two names, receive confirmation and obtain venue directions; authorized committee sees accurate headcount and exports; unauthorized access is denied. No production launch until verified.
